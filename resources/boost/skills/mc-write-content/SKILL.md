# Write Web Content

## Principles

- Start from the job the visitor is trying to complete and the language they use.
- One page serves one primary goal and one primary action.
- Place proof near every claim; keep missing data explicitly missing.
- SEO serves the same intent as the content. There is no separate version written for the search engine.

## Procedure

1. Read the request, project instructions, existing documents, the site or mockup, and the supplied facts.
2. Separate proven facts, inferences, and unknowns. Ask once for missing facts without which the deliverable would be misleading or unusable.
3. Select the expected unit and read its reference:
   - [references/product.md](references/product.md) for a product record;
   - [references/page-brief.md](references/page-brief.md) for a page brief;
   - [references/seo-conversion-review.md](references/seo-conversion-review.md) for a review.
4. Write in French using the confirmed tone. Mark every missing factual element as `[TO PROVIDE: ...]`; never fill a gap with plausible-sounding copy.
5. Verify alignment between intent, hierarchy, proof, action, and metadata. For SEO guidance that depends on current rules, consult an up-to-date primary source.
6. Report the result, evidence, assumptions and unverified items. A review remains a report and does not modify the page.

## Prohibited

- Invented figures, testimonials, customers, guarantees, prices, or results.
- Manufactured urgency, fake social proof, hidden costs, or deceptive mechanics.
- Copying a competitor's wording.
- Modifying code, tracking, a campaign, or a published page.
