# Page Brief

Create one French-language file per page in the location declared by the project, using kebab-case.

## Required Content

1. **Goal and primary action**: what the visitor comes to accomplish; clearly subordinate secondary actions.
2. **Structure**: sections in reading order, each section's role, message, proof, and element type. Identify first-viewport content.
3. **Copy v0**: headline options, body copy, calls to action named after their outcome, strictly necessary fields, errors, and confirmation. Keep `[TO PROVIDE: ...]` markers.
4. **On-page SEO**: target queries with intent and the page's legitimate fit, title, meta description, `h1`, `h2`/`h3` outline, slug, internal links, alt-text intent, and applicable structured data.
5. **Implementation requirements**: canonical, indexation, redirects, sitemap, structured data, performance budget, and measurement events when they are genuinely planned.
6. **Open points**: missing facts, assumptions, and pending decisions.

## SEO Rules

- One page covers one coherent intent family; prevent two pages from competing for the same need.
- Titles and headings describe the content honestly, without artificial keyword accumulation.
- Every page must be reachable through descriptive internal links.
- Cite search volume and difficulty only with the measurement tool and date; otherwise leave them unknown.
- Structured data describes only content visible on the page.
