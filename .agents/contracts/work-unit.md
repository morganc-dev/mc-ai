# Work Unit Contract

Use when assigning work to a specialized role. Include only fields that materially affect execution.

```text
Objective and observable outcome:
Scope:
Out of scope:
Inputs and sources of truth:
Constraints:
Allowed files:
Required validation:
Dependencies:
Escalate if:
```

A unit must have a single owner and remain understandable without rereading the full conversation. If two units depend on the same decision, that decision belongs to the orchestrator and must be settled before either unit starts.
